## 项目简介

「北京地理信息站」是一款面向北京区域（含研究区 / 全域两种范围）的交互式 WebGIS 工具，将 **SRTM 高程数据（DEM）**、**遥感影像数据** 与 **Leaflet 地图** 结合，在浏览器端完成等高线生成、坡度坡向分析、地形剖面、通视分析、热岛（UHI）分析、水体提取等地理分析，并支持 **SVG / GeoJSON 数据导出** 与 **可扩展的 JS 插件系统**。


## 功能特性

### 🗺 图层（layers）
- 多底图切换：卫星影像（Esri）、地形（Esri Topo / OpenTopoMap）、街道（OSM）、浅色（Esri Light）、素色（叠加分析专用）
- 栅格叠加：晕渲（明→暗）、等高线（含「经典棕 · 计曲线加粗」风格）
- **KML 图层**：内置 overpass-turbo OSM 导出的兴趣图层（gzip + base64 内嵌，随文件分发）
- 图层显隐控制、透明度调节、图层层级管理

### 🔍 查询（query）
- 地名检索：按关键词定位最近地名
- 坐标查询：支持 **GCJ02** 与 **WGS84** 双坐标系显示与换算
- 区县归属查询、框选范围内要素查询

### 📊 分析（analysis）
- **高程分析**：平均高程、最高 / 最低点、≥500m 占比、按区县统计（区县平均高程排序、区域框选统计）
- **地形分析**：坡度 / 坡向、地形剖面（剖面长度、平均坡度）、晕渲图
- **水文分析**：水体提取（2026-10 数据集）、≥0.3km² 水体数统计
- **热环境分析**：LST 昼夜温度（MODIS 合成，如 MODLT1T）、UHI 城市热岛均值、最暖前四区县
- **植被分析**：EVI 增强植被指数（月最大合成，如 2015.02 / 2016.05）、反射率
- **测量工具**：测距、面积测量、通视分析（可见 / 被遮挡判断）

### 🖨 生成（generate）
- 导出当前分析成果为 **SVG** 矢量图
- 导出要素为 **GeoJSON** 数据
- 支持研究区 / 当前视野两种导出范围

### 🗃 数据（data）
- 内置北京区域 **SRTM DEM** 高程网格（逐格高程查询、双线性插值）
- 遥感数据集目录与元信息展示
- 数据来源与许可声明页

### 🔌 插件（plugin）
- 浏览器端 **JavaScript 插件系统**（接口 v1.0）：插件代码在页面权限内运行，可读取内置数据、调用地图 API
- 支持插件的 **新建 / 编辑 / 启用 / 停用 / 删除 / 恢复示例**
- 内置示例插件：极值点标记（最高 / 最低点探测）、圆形缓冲区、经纬网格、随机采样分析

### 🔗 其他能力
- **URL 状态分享**：通过 URL hash（`#z=...`）保存地图视图与状态，可复制分享
- **加载性能**：并行解压 DEM 与遥感栅格数据，缩短首屏等待
- 全局接口 `window.BJGEO`，方便浏览器控制台调试与二次开发


## 技术栈

| 类别 | 技术 |
|---|---|
| 地图引擎 | Leaflet（渲染、交互、图层管理） |
| 数据可视化 | D3.js（等高线、SVG 渲染） |
| 分析数据 | SRTM DEM、MODIS 遥感合成（LST / EVI / 反射率）、水体提取数据、OSM（overpass-turbo）兴趣图层 |
| 坐标系统 | GCJ02 / WGS84 支持与换算 |
| 架构 | 单文件 HTML，零依赖安装、零后端、可离线运行 |

## 环境要求

- 现代浏览器：Chrome / Edge / Firefox（推荐最新版）
- 无需安装任何环境、无需网络连接（数据全部内嵌，可完全离线运行）
- 建议屏幕分辨率 ≥ 1280×720 以获得最佳面板布局

## 快速开始

### 方式一：直接打开（推荐快速体验）

用浏览器（Chrome / Edge / Firefox）直接双击打开 `index.html` 即可，无需安装任何环境。

> 若部分浏览器对 `file://` 协议有安全限制，推荐使用方式二。

### 方式二：本地静态服务器

```bash
# 任选其一，在项目目录下执行
python3 -m http.server 8080
# 或
npx serve .
```

浏览器访问 `http://localhost:8080`。


## 插件系统

插件是运行在页面权限内的 JavaScript 代码，必须返回一个插件定义对象（`{ name, onload / 生命周期方法 }`）。

### 可用 API

| 方法 | 说明 |
|---|---|
| `api.activateTab(name)` | 切换标签页：`layers` / `query` / `analysis` / `generate` / `data` / `plugin` |
| `api.addLayer(layer, opts)` | 向地图添加图层（支持 `name` / `tag` / `desc` 标注） |
| `api.chart(dom, option)` | 在指定 DOM 节点渲染图表（ECharts 配置格式） |
| `api.dom(id)` | 获取页面 DOM 节点 |
| `api.coord([x, y])` | 坐标转换（经纬度 → 屏幕坐标） |
| `api.value(v)` | 数值格式化 / 换算辅助 |

### 地理数据 API（`geo.*`）

| 方法 | 说明 |
|---|---|
| `geo.demAt(lon, lat)` | 查询某点 DEM 高程值 |
| `geo.demBilinear(lon, lat)` | 双线性插值高程（更平滑） |
| `geo.demSlopeAspect(lon, lat)` | 查询坡度 / 坡向 |
| `geo.demCellAreaKm2(lat)` | 计算某纬度网格单元面积（km²） |
| `geo.distM(lon1, lat1, lon2, lat2)` | 两点球面距离（米） |
| `geo.rasterAt` | 栅格数据取值 |
| `geo.bookmarks.v1` / `geo.plugins.v1` | 内置书签 / 插件数据接口 |

> 插件详细编写规范可打开应用 →「插件」标签页查看内置示例源码；也可在浏览器控制台通过 `window.BJGEO` 全局对象调试。

## 二次开发与自定义

- **替换数据范围**：项目数据为北京区域。如需扩展其他区域，可替换内嵌的 DEM / 遥感栅格数据（源码中「DEM 网格」「KML 新图层」等模块有明确的数据装载入口）
- **新增兴趣图层**：参照内置 KML 图层的方式（overpass-turbo OSM 导出 → gzip + base64 内嵌），可添加自定义矢量图层
- **扩展插件**：通过「插件」标签页新建插件，或直接调用 `window.BJGEO` 全局 API 编写更复杂的扩展

## 常见问题

**Q：为什么打开后地图 / 分析没数据？**
A：请使用 Chrome / Edge 等现代浏览器，并优先通过本地服务器（`python3 -m http.server`）方式打开；部分老浏览器不支持现代 JS 语法。

**Q：可以修改数据范围吗？**
A：本项目数据为北京区域（含研究区与全域切换）。如需扩展其他区域，需要替换内嵌的 DEM / 遥感栅格数据，属于二次开发范畴。

## 数据来源与许可

本项目仅供学习与研究使用，少部分代码由AI生成。

- 底图版权归各数据源所有：Esri、OpenStreetMap（OSM）、OpenTopoMap
- DEM 数据来源于 **SRTM**（Shuttle Radar Topography Mission）
- 遥感合成数据来源于 **MODIS**（LST / EVI / 反射率，NASA）
- 兴趣图层来源于 **overpass-turbo（OSM 数据）**
- 内置开源库：Leaflet（BSD-2-Clause）、Apache ECharts / ZRender（Apache-2.0 / BSD-3-Clause）；许可声明与全部数据来源详见页内「数据 → 数据来源与许可」
